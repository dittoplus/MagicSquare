## 1. 배경 및 목표

### 1.1 Mom Test 진짜 문제

> 빈칸 2개 4×4 과제에서 **10개 선(행·열·대각) 합 34**를 빠짐없이 확인하지 못한 채 “끝났다”고 판단해, **약 20분**을 다시 쓰게 된다.

### 1.2 주제 (1문장)

**부분 마방진(빈칸 2개, 1~16, 합 34)을 “완성”으로 볼 때, 10개 선을 빠짐없이·재현 가능하게 판별할 수 있어야 한다.**

### 1.3 R-G-I-O

| | 내용 |
|---|------|
| **Role** | 빈칸 2개짜리 4×4 마방진 과제를 **손으로/코드로** 풀고 맞는지 확인하는 **학습자** |
| **Goal** | 제출·완료 전에 **10개 선 모두 합 34**인지 **한 번에 확신** — 대각선 누락 등 **재작업(~20분)** 방지 |
| **Input** | `4×4` 격자, 값 `0` 또는 `1..16`, 빈칸 **정확히 2개** |
| **Output** | **완성 판정**: 10선 전부 34 → 통과 / 하나라도 불일치 → **미완성·거부** (명확한 실패 신호) |

### 1.4 기술 목표 (제품)

부분적으로 비어 있는 4×4 격자(빈칸 `0`)를 받아:

- **완성 판정(FR-04):** 채워진 격자에 대해 **10개 선** 합이 모두 **34**인지 **결정론적으로** 판별한다.
- *(후속)* **해 탐색(FR-05):** 두 빈칸에 값을 배치해 완성 가능하면 `int[6]` 반환, 불가면 `NO_SOLUTION`.
- **입력 계약(FR-01):** 무효 입력은 표준 `code`/`message`로 **차단**한다.

## 4. 기능 요구 (FR)

| ID | 요구 | 우선순위 | Mom Test 연결 |
|----|------|----------|---------------|
| **FR-01** | 4×4, `0`/`1..16`, 빈칸 2개, 중복 없음 — 위반 시 오류 반환, Domain **미호출** | P0 | 입력 계약 |
| **FR-04** | 완전 채워진 격자: **10선 합 34** 판정 — **주·부대각 모두** 포함 | **P0 (초안 1차)** | SC-1, SC-2 |
| **FR-02** | 빈칸 2곳 좌표 탐색 (행 우선) | P1 | 후속 |
| **FR-03** | `1..16` 대비 누락 두 수 `{a,b}` | P1 | 후속 |
| **FR-05** | `{a,b}` 두 배치 시도 → 해 또는 `NO_SOLUTION` | P1 | 후속 |

### FR-04 상세 (초안 1차 핵심)

- 행·열만 맞고 **대각선 1개 이상** 틀린 격자 → **거부** (완성 아님).
- 행·열만 검사하는 구현 → **AC-04 위반**.
- 판정 결과는 **동일 입력 → 동일 출력**(결정론).

## 5. 오류 계약 (Boundary)

| code | 조건 |
|------|------|
| `INVALID_SIZE` | 4×4 아님 |
| `INVALID_VALUE_RANGE` | `0`/`1..16` 밖 |
| `INVALID_ZERO_COUNT` | 빈칸 ≠ 2 |
| `DUPLICATE_VALUES` | 1..16 중복 |
| `NO_SOLUTION` | 유효 입력, 해 없음 *(FR-05, 후속)* |

검증 **우선순위:** size → value → zero count → duplicate → Domain.

## 6. API (초안)

```text
solve_magic_square(grid: list[list[int]]) -> list[int] | dict
```

| 결과 | 형태 |
|------|------|
| 성공 (후속 FR-05) | `[r1, c1, n1, r2, c2, n2]` (1-index) |
| 입력 오류 | `{"code": "...", "message": "..."}` |
| 해 없음 | `{"code": "NO_SOLUTION", "message": "..."}` |

**초안 1차 Domain API (FR-04):**

```text
validate_ten_lines(grid: list[list[int]]) -> bool
```

- `True`: 10선 모두 합 34  
- `False`: 하나라도 ≠ 34 (또는 미완성 격자는 호출 전 Boundary에서 차단)

## 8. 테스트 전략

### 8.0 원칙

- **판단(Decision)** 이 있는 항목만 테스트화.
- Mom Test **SC-1~SC-3** → Domain 테스트 케이스명·주석에 추적.

### 8.1 Boundary

- FR-01 위반 → `code`/`message`, Domain 미호출.

### 8.2 Domain (FR-04 — 초안 1차)

| TC-ID | 시나리오 | Mom Test |
|-------|----------|----------|
| D-04-01 | 10선 모두 34 → `True` | SC-2 |
| D-04-02 | 행·열만 34, **부대각 ≠ 34** → `False` | SC-1, SC-3 |
| D-04-03 | 행·열만 34, **주대각만** 확인한 케이스와 동치 거부 | SC-1 |
| D-04-04 | 동일 격자 2회 → 동일 결과 | SC-3 |

### 8.3 Test Loop (초안 1차)

|------|------|
