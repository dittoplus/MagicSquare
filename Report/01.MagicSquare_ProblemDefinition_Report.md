## 1. 목적

4×4 부분 마방진(빈칸 2개, 1~16, 합 34) 과제에서 **솔루션 없이** 사용자 불편을 드러내고, **진짜 문제**를 한 문장으로 고정한 뒤 PRD 초안(R-G-I-O·성공 기준)으로 추적 가능하게 한다.

**방법:** Rob Fitzpatrick *Mom Test* — 과거 행동·시간·비용만 수집; 미래 가정·기능 제안 금지.

---

## 2. 페르소나

**부분 마방진(빈칸 2개) 학습자** — 프로그래밍·수학 과제로 4×4 격자를 손으로 또는 코드로 풀고, “맞는지”를 스스로 확인해야 한다.

---

## 3. Mom Test 인터뷰 요약

### 3.1 질문 1 (과거 행동)

> 가장 **최근**에, 빈칸 **2개** 남은 4×4 마방진(합 34) 과제를 **처음 손대기 시작한 순간**부터 “일단 끝”이라고 생각할 때까지, **실제로 한 일**을 순서대로 말해 줄 수 있어?

### 3.2 답변 (과거 사실)

> “**지난주 OO 과제**에서 **빈칸 2개** 넣고 **행·열·대각선 합** 맞췄는데 **대각선 하나를 빼먹어서 20분 날렸다**.”

### 3.3 사실성 평가

| 항목 | 판정 |
|------|------|
| 과거 시점 | ✅ “지난주 OO 과제” |
| 구체 행동 | ✅ 빈칸 2개 채움, 합 확인 |
| 측정 가능 비용 | ✅ 약 20분 |
| 미래·가정 | ✅ 없음 |
| 솔루션 섞임 | ✅ 없음 |

**미확인 (후속 인터뷰 권장):** “끝” 직전에 **10선 중 몇 개**를 확인했는지, 틀림을 **언제·어떻게** 알았는지.

---

## 4. 표면 문제 vs 진짜 문제

### 4.1 표면 문제 (잘못된 정의 — 설계에 사용하지 않음)

> “4×4 마방진 **대각선까지 자동으로 검증해 주는 프로그램**을 만들면, 과제에서 **20분** 같은 낭비를 줄일 수 있다.”

- 솔루션(프로그램·자동 검증)이 문제 정의에 섞인 **전형적 오류**.
- 인터뷰 답변에는 없었으나, 불편에서 **잘못 뛰기 쉬운** framing으로 기록.

### 4.2 진짜 문제 (한 문장)

> **빈칸 2개 4×4 과제에서 10개 선(행·열·대각) 합 34를 빠짐없이 확인하지 못한 채 “끝났다”고 판단해, 약 20분을 다시 쓰게 된다.**

- **누가:** 학습자  
- **언제:** 과제 완료·제출 직전  
- **무엇이 막히는지:** 10선 전체에 대한 **확신·재현 가능한 판정**  
- **손실:** 예측 못 한 **재작업 시간(~20분)**

---

## 5. Mom Test 증거 (인용)

1. “**지난주 OO 과제**에서”
2. “**빈칸 2개 넣고 행·열·대각선 합 맞췄는데**”
3. “**대각선 하나를 빼먹어서 20분 날렸다**”

---

## 6. 문제 정의 → 제품 초안 (R-G-I-O)

| | 내용 |
|---|------|
| **Role** | 빈칸 2개짜리 4×4 마방진 과제를 **손으로/코드로** 풀고 맞는지 확인하는 **학습자** |
| **Goal** | 제출·완료 전에 **10개 선 모두 합 34**인지 **한 번에 확신** — 대각선 누락 등 **재작업(~20분)** 방지 |
| **Input** | `4×4` 격자, 값 `0` 또는 `1..16`, 빈칸 **정확히 2개** |
| **Output** | **완성 판정**: 10선 전부 34 → 통과 / 하나라도 불일치 또는 미검 → **미완성·오류** (명확한 실패 신호) |

### 주제 (1문장)

**부분 마방진(빈칸 2개, 1~16, 합 34)을 “완성”으로 볼 때, 10개 선을 빠짐없이·재현 가능하게 판별할 수 있어야 한다.**
